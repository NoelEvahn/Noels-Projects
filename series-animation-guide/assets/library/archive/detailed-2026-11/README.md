# Detailed rig (archived 2026-11-19)

The "detailed" character and cat models used in episode 3 drafts: coloured iris rings, catchlights, fingered hands,
almond slit-pupil cat eyes. The user found them too anime and inconsistent with episodes 1-2, so the library went back to
the series look (white ball eyes with black dot pupils, bulb nose, ball hands). Kept here for reference or reuse.

Import from here instead of the library root to use them: `archive/detailed-2026-11/character.js`, `cat.js`, `animal.js`.
