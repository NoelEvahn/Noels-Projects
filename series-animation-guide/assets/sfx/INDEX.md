# SFX Library

Source: Google Drive folder "Viewcci Sound Effects" (24 files, copied 2026-11-19). Use these for every episode, every format.

| Folder | Use for | Files |
|---|---|---|
| `popup/` | UI pops, counter ticks, captions and badges appearing | `click`, `pop`, `pop_bubbly`, `pop_deeper` |
| `reveal/` | reveals, big hits, tier changes, title card | `reveal`, `reveal_2`, `magic_reveal`, `reveal_vine_boom` |
| `suspense/` | risers leading into a big moment (use before the payoff or the silence window) | `riser`, `riser_2`, `riser_long`, `riser_fades_out` |
| `transition/` | scene changes, camera flashes (hook flash), shutter stills | `camera_shutter`, `camera_shutter_cinematic`, `transition_build_up`, `transition_riser` |
| `zoom/` | whooshes on snap zooms and punch-zooms only | `whoosh`, `whoosh_2`, `whoosh_cinematic`, `whoosh_deep` |

Rules: SFX stay under the voices and the music (see MASTER_PROMPT.md "Mix"). Never add an SFX to every cut.
